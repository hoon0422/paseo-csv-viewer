## Data, ownership, and remaining platform gate

The daemon reads selected source files in place. External desktop drops and the local picker work only when the panel's selected host is that desktop's own daemon; they do not upload a whole file. The plugin has the daemon user's file, process, and network access. Preparation uses owned temporary DuckDB database/WAL and may spill on the daemon's temporary disk; available disk must cover the workload. Closing or replacing the source cleans up owned data.
