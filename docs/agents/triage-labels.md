# Triage labels

Map canonical triage roles to these GitHub label names:

| Canonical role | Label in this tracker | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation needed |
| `needs-info` | `needs-info` | More information needed |
| `ready-for-agent` | `ready-for-agent` | Fully specified for an agent to implement |
| `ready-for-human` | `ready-for-human` | Human implementation needed |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill names a triage role, use the corresponding label in this table.
